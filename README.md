# JARVIS Desktop

Персональный центр управления Windows с отдельным графическим интерфейсом и пиксельным питомцем. Питомец остаётся поверх рабочего стола, а короткий клик открывает главное окно JARVIS без консоли.

## Что доступно

- Тёмно-синий интерфейс на PySide6 и Qt Quick/QML с анимированным ядром JARVIS.
- История последних 100 команд в `%LOCALAPPDATA%\JARVIS\history.json`.
- Запуск установленных Win32 и UWP-приложений по названию, русским псевдонимам и нечёткому совпадению.
- Раздел приложений с поиском, цифровыми пресетами `1–5`, VPN и Claude Code.
- Игровой режим с предварительным просмотром браузеров и приложений с заметной GPU-нагрузкой.
- Безопасный `kill <программа>` с показом найденного дерева процессов перед подтверждением.
- Локальные заметки с добавлением, редактированием и удалением.
- Команды питания Windows: выключение, таймер выключения, перезагрузка, сон и отмена таймера.
- Системный трей: открыть JARVIS, показать или скрыть питомца, полностью выйти.
- Один экземпляр приложения: повторный запуск активирует уже работающий JARVIS.

Опасные действия никогда не выполняются сразу. Игровой режим, `kill`, команды питания и очистка истории сначала показывают отдельное окно подтверждения.

## Основные команды

| Команда | Действие |
| --- | --- |
| `chrome`, `открой VS Code` | Запустить приложение |
| `/apps` | Открыть раздел приложений |
| `1` … `5`, `пресеты` | Быстрые запуски |
| `VPN`, `Claude code` | Персональные команды |
| `заметки` | Открыть локальные заметки |
| `/game preview` | Показать процессы игрового режима |
| `/game`, `Протокол игры` | Подготовить включение игрового режима |
| `kill chrome` | Найти приложение для принудительного завершения |
| `выключить пк(30)` | Выключить ПК через 30 минут |
| `перезагрузка`, `спящий режим` | Управление питанием |
| `/clear` | Очистить историю после подтверждения |
| `/help` | Открыть встроенную справку |
| `/exit` | Полностью завершить JARVIS |

## Запуск из исходников

Требуется Windows 10/11 x64 и Python 3.12 или новее.

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python assistant.py
```

При запуске появляется питомец. Нажмите на него или дважды нажмите значок JARVIS в системном трее, чтобы открыть окно. Крестик скрывает окно в трей и не завершает приложение.

## Сборка EXE

### Личная версия интерфейса

Текущий интерфейс и личная версия существуют параллельно:

```powershell
# Текущий интерфейс с питомцем
python assistant.py

# Личная голосовая оболочка без питомца
python personal_assistant.py
```

Личная версия использует отдельный `qml/personal/PersonalMain.qml`. В ней доступны
поле команд, последние действия, быстрый запуск с нативными значками программ,
персональные протоколы и статистика запусков с показателями ЦП, видеокарты, памяти
и дисков. Программы из быстрых пресетов не повторяются в разделе часто
используемых. Цвета personal-интерфейса собраны в семантические токены
`qml/personal/PersonalTheme.qml`, чтобы будущие темы не меняли структуру страниц.

Для отдельной сборки personal-версии:

```powershell
python -m PyInstaller --noconfirm --clean --distpath dist --workpath .personal_build personal_assistant.spec
```

Готовый файл: `dist\JARVIS-Personal.exe`.

### Текущая версия

```powershell
python -m pip install -r requirements-dev.txt
python -m PyInstaller --noconfirm --clean --distpath dist --workpath .desktop_build assistant.spec
```

Готовый файл находится в `dist\assistant.exe`. Путь и имя сохранены совместимыми со старой терминальной сборкой, поэтому существующий ярлык запускает новый GUI. Сборка не открывает консольное окно и включает QML, иконки, спрайты питомца и начальный индекс программ. Соседний `notes.json` используется только как источник первой миграции и при сборке не удаляется.

## Локальные данные

JARVIS хранит пользовательское состояние в `%LOCALAPPDATA%\JARVIS`:

- `history.json` — последние 100 команд;
- `notes.json` — заметки;
- `pet_state.json` — позиция питомца;
- `programs.json` — обновлённый локальный индекс приложений.

Существующие заметки из прежней версии копируются автоматически. Если JSON-файл повреждён, JARVIS сохраняет его рядом с суффиксом `.corrupt-<дата>` и запускается с безопасным пустым состоянием.

## Тесты

```powershell
python -m unittest discover -v
```

Тесты используют моки для команд питания и управления процессами и не должны выключать компьютер или закрывать пользовательские приложения.
