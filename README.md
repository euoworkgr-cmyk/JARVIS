# JARVIS

Терминальный ассистент для Windows, который быстро открывает установленные программы. Интерфейс построен как рабочая CLI-сессия: история остаётся на экране, команды вводятся в отдельной строке, а результат запуска показывается сразу.

## Функционал
- Запуск программы по названию: `chrome`, `telegram`, `vs code`.
- Команды на русском и английском: `открой VS Code`, `run calculator`.
- Нечёткий поиск и русские псевдонимы: `вс код`, `хром`, `калькулятор`.
- Быстрые команды `/apps`, `/help`, `/clear` и `/exit`.
- Игровой режим: `Протокол игры` или `/game` закрывает браузеры и программы с заметной GPU-нагрузкой.
- Прямое принудительное завершение найденных деревьев процессов через `kill()`.
- Команда `VPN` открывает Happ Terminal VPN.
- Команда `Claude code` запускает ярлык Claude Code с рабочего стола.
- Пресеты по цифрам: `1` — новое окно Яндекс Браузера, `2` — ChatGPT, `3` — VS Code, `4` — Telegram, `5` — Камера.
- Команда `пресеты` показывает таблицу всех цифровых пресетов.
- Команда `заметки` открывает встроенный терминальный режим заметок с командами `добавить`, `удалить`, `очистить` и `назад`.
- `kill <программа>` находит запущенное приложение, запрашивает подтверждение и принудительно завершает всё дерево процессов.
- Happ Terminal VPN запускается в отдельной консоли и не перехватывает ввод JARVIS.
- Предпросмотр без закрытия программ: `/game preview`.
- Вывод всех найденных программ по команде `/apps` или `список программ`.
- Видимые сообщения об успешном запуске и ошибках.

## Как запустить
1. Перейдите в папку `dist`.
2. Запустите файл `assistant.exe`.
3. Введите название программы или команду, например `открой VS Code`.

## Особенности новой версии
- **Интерфейс в духе Claude Code**: тёмная терминальная сессия, компактная шапка, рамка ввода и спокойная визуальная иерархия.
- **Корректный запуск**: UWP-приложения, Win32-программы и URL открываются подходящим для них способом.
- **Улучшенный поиск**: добавлены транслитерация и гибкий нечёткий поиск.
- **Автоматический индекс**: JARVIS загружает список приложений Windows из `programs.json`.
- **Безопасный игровой режим**: перед закрытием JARVIS показывает одну строку на приложение и запрашивает подтверждение. Закрывается всё дерево процессов. Системные процессы Windows и NVIDIA, JARVIS, Fortnite, Broken Arrow, Steam и Epic Games Launcher защищены от закрытия.

## Обновление списка программ
Если вы установили новую программу и ассистент её не видит, запустите скрипт `get_programs.py` через Python:
```bash
py get_programs.py
```
После этого пересоберите EXE (если вы разработчик) или просто используйте `py assistant.py`.
